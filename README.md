# Station Quiz — crédits des illustrations

Ce dépôt héberge uniquement les pages publiques de crédits des illustrations utilisées dans les vidéos
de la chaîne Station Quiz.

Chaque épisode a sa page, `credits_<épisode>.html`. Pour chaque illustration, elle indique l'auteur, le
titre, la source, la licence, les modifications et les mentions. Le lien de la page figure dans la
description de la vidéo.

Ce dépôt ne contient pas le programme Station Quiz.
